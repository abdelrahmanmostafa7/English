# American English Mastery Reference

General American pronunciation, ~3000 core vocabulary items, expressions, connected speech, and professional communication (A1–C2).

## Open

Open `index.html` in a browser.

## Save as PDF

**File → Print → Save as PDF** (A4). Or use the **Print / Save PDF** button.

## Rebuild

```bash
cd american-english-mastery
python3 build.py
```

Vocabulary data lives in `data/vocab.json` (~3050 lexical items).
